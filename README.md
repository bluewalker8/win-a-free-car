# Win a Free Car — Jasper Walker

YouSet interview presentation. Deploy this folder to Netlify.

## Deploy

1. Unzip.
2. Put the folder in a GitHub repo (new repository, upload the files).
3. Open [app.netlify.com](https://app.netlify.com) → **Add new site** → **Import an existing project**.
4. Pick the repo. Build settings are already in `netlify.toml`.
5. Deploy. Send YouSet the `*.netlify.app` URL.

Do not drag this zip onto Netlify Drop. That path is for a finished static folder, and this app needs a build.

## Local

```bash
npm install
npm run dev
```
